# Gate 22C — Targeted Compositional Coverage Intervention

## Question
Can the Gate-22B diagnosed OOD failure be corrected by improving compositional
training coverage alone, without changing the Privacy Agent model family?

## Frozen
- multinomial logistic regression
- C = 1.0
- Privacy feature semantics
- original Gate-21A train/test split
- Gate-22A OOD benchmark
- hard policy shield
- all upstream scientific semantics

## Changed component
Only the training-data coverage of interaction-rich policy states.

## Dataset rationale
The augmentation is generated by the same deterministic privacy oracle but
explicitly excludes every core policy-state combination present in the Gate-22A
OOD benchmark.

Eligible augmentation states contain:
- wrong-jurisdiction precedence;
- missing-evidence precedence;
- at least two simultaneous violations;
- audit + policy-violation interactions.

This tests whether the problem is insufficient compositional coverage before
attributing failure to model capacity.

## Anti-leakage
OOD core combinations and augmentation combinations must have zero overlap.

- augmentation CSV
- OOD predictions before/after
- dataset-methodology JSON
- metrics/checks JSON
- PNG + PDF publication figures

## PASS
- zero OOD/augmentation overlap
- OOD action accuracy >= 0.70 and improved
- OOD action macro-F1 >= 0.60 and improved
- OOD assessment accuracy >= 0.70
- ID action accuracy >= 0.95
- unsafe executed actions after shield = 0
- publication figures generated
