# ITU-T Y.3172, AI Readiness and standards mapping

| Y.3172 node | MedVerse-Agent function | Governance / readiness emphasis |
|---|---|---|
| SRC | Patient/scenario observations, DT/network evidence, Korean policy sources | Provenance, contextualization, lawful collection |
| C | Source IDs, timestamps and institution-bounded evidence capture | Evidence integrity, role separation |
| PP | Policy chunking, Korean/English representation, explicit missingness and normalization | Data governance and traceability |
| M | Institutional assessment and action proposal | Model provenance, validation and domain AI |
| P | KR retrieval, jurisdiction/mandate/purpose/evidence checks | Trust, policy application, human authority |
| D | Distribution of permitted workflow outputs and scoped views | Minimum-necessary institutional exchange |
| SINK | Medical Metaverse operator workspace and audit receipts | Human collaboration and supervised execution |

## Standardization opportunities identified

1. **Institutional Agent Descriptor** — identity, mandate, observation scope, knowledge access, action scope and jurisdiction.
2. **Action Authority Descriptor** — owner, preconditions, required evidence, policy basis, jurisdiction, validity and expiry.
3. **Digital Twin Context Envelope** — state version, freshness, integrity, provenance, purpose, recipient, authority context and policy snapshot.
4. **Coordination-state vocabulary** — AGREEMENT, COMPLEMENTARY, CONDITIONAL_HARMONIZATION, INSTITUTIONAL_CONFLICT, POLICY_CONFLICT, INSUFFICIENT_EVIDENCE and HUMAN_AUTHORITY_REQUIRED.

These are proposed healthcare coordination/domain-profile opportunities, not assertions that existing Recommendations contain no related functions.
