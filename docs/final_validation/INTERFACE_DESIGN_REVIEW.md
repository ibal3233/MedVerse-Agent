# Reference repositories and the new judge workbench

This implementation borrows interaction principles, not claims of comparative superiority:

- SAMAAM: inspectable source-to-action boundary and clinician-versus-regulator authority distinction.
  Inspected `design/FRONTEND-PLAN.md`, `app/policy_node.py`, `app/pipeline.py` and frontend routes.
- Nakheel Doctor: separate informational retrieval from deterministic action policy, explicit uncertainty,
  evidence membership checking and configuration-held authorization. Inspected `app.py`, `policy_engine.py`,
  `policy_evidence.py` and `knowledge_base.csv`.
- LawThinker: exploration/verification separation. Inspected `src/agents/law_thinker_agent.py`,
  `src/tools/check_tool.py`, `law_tool.py`, and `memory_tool.py`. It is a research reference, not identified
  by ITU as a winner in the supplied Saudi winners list.

The new MedVerse interface is original implementation in standard HTML/CSS/JavaScript with a standard-library
Python local server. No competitor asset or code was transplanted. No competitor application was freshly
executed end-to-end in this turn; the source packages and prior audit evidence were reviewed.

Five pages in the application:
1. Clinical workspace: virtual representation, progressive events, five scoped agents and harmonization state.
2. Korean policy evidence: role-filtered bilingual lookup, exact identifiers, source links and interpretation status.
3. Decisions and receipts: actual proposal identity, current validation, provenance and mock side effects.
4. Experimental evidence: real saved results, stateful-control tie, errors and dependency limitations.
5. Readiness: concrete Y.3172 functional mapping and unresolved clinical/legal/operational requirements.

The execution coordinator is named Institutional Harmonization Coordinator. It is not a Security Coordinator,
a sixth peer, a clinician or a government regulator. The observer console can inspect each separate role view;
that does not give one agent access to other institutions' raw patient data.

Design choices are engineering judgments, not evidence that this interface will win first prize. Source links
and mock human-review tickets do not themselves confer legal authority. The 3D-like avatar is an illustrative
virtual representation, not a clinically validated Digital Twin or immersive metaverse deployment.
