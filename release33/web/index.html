How to read agent coverage
Decision opportunities count a proposal again when it is reconsidered at a later event. They are not independent samples. PREPARE and COMMIT counts are actual permitted effects; BLOCK / ESCALATE counts describe decisions, not executions.
The live proposal inputs are frozen institution-owned modeled contracts, not learned or LLM-generated actions. No per-agent predictive-accuracy claim is made.


What is connected—and what is not
Connected in this release
Unchanged commitment engine, per-proposal timing contracts, scoped institutional projections, proposal-to-effect receipts, modeled authority changes, original source-linked evidence service, and preserved DT application on the same local host.
Not claimed
Clinical or legal approval; arbitrary-language independence; cryptographically authenticated remote institutions; unique superiority over bounded waiting; repaired original C01/C02 workflows; production deployment or full ITU conformance.
Same host, separate modeled sessions
The original clinical / DT workspace remains available without commitment-policy changes. The commitment workspace does not manufacture telemetry from action contracts. It displays received DT context only when an actual modeled envelope has been released.
Mentor-facing reusable architecture
The coordinator and validation interfaces can be reused. A new domain still needs its own sources, mandates, observation scopes, action contracts, authority records, and reference specification. No education deployment is validated here.
Three bounded contributions
Clinical–cyber handoff; purpose-bound research alternatives; policy-context preservation during DT exchanges. These are modeled coordination requirements, not demonstrated omissions from Korean law or ITU standards.
